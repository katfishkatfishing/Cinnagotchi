# Cinnagotchi

A desktop and tamagotchi companion with Cinnamon from Sanrio!
The ONLY Cinnamon you will ever need that during Autumn that loves cinnamon rolls too.

## Features

- IDK what;s on the desktop feature for now
- Cinnamon with animations
> Tamagotchi
> 3 button controls
> 2-inch lcd screen
> Powered by esp-32 S3 WROOM-1
